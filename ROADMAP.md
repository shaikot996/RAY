# RAY Roadmap

RAY 1.0.0 is an initial public development release. The following directions are planned or exploratory and are not commitments to a specific release date.

## Near term

- improve error messages and argument validation;
- expand regression coverage;
- benchmark symbolic performance;
- exploit tensor symmetries to reduce redundant component calculations;
- improve sparse/high-dimensional workflows;
- add more example spacetimes;
- improve documentation notebooks.

## Geometry

- coordinate transformations;
- geodesics and geodesic deviation;
- orthonormal frames;
- tetrads/vielbeins;
- spin connection;
- Cartan structure equations;
- differential forms and exterior calculus;
- ADM / 3+1 decomposition;
- additional polynomial curvature invariants.

## xAct interoperability

- import/export RAY metrics and tensors;
- component-to-abstract-index conversion;
- xTensor/xCoba interoperability;
- cross-validation of curvature conventions;
- optional use of xAct for canonicalization and abstract tensor algebra.

## Higher-dimensional gravity and supergravity

- p-form field strengths;
- wedge products and Hodge duals;
- form-field Bianchi identities;
- stress tensors for fluxes;
- gamma-matrix utilities;
- spinors and covariant spinor derivatives;
- Killing-spinor equations;
- bosonic supergravity equations;
- warped products;
- dimensional reduction;
- compactification helpers;
- flux compactifications;
- effective lower-dimensional quantities.

## Longer term

- documentation paclet/notebook system;
- automated benchmark suite;
- public paclet distribution;
- interoperability with other Wolfram tensor packages;
- research-oriented modules for string compactification and supergravity.
