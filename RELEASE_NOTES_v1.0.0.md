# RAY 1.0.0 — Initial Public Development Release

RAY 1.0.0 is the first public development release of **RAY — Relativity and Geometry Toolkit**.

This release establishes the explicit-component tensor engine and Raychaudhuri-kinematics interface.

## Highlights

- arbitrary-dimensional explicit metrics;
- configurable upper/lower tensor index positions;
- Christoffel, Riemann, Ricci, Einstein, and Weyl tensors;
- curvature invariants including the Kretschmann scalar;
- human-readable nonzero-component tables;
- normalized non-null congruences;
- expansion, acceleration, shear, and vorticity;
- Raychaudhuri equation evaluation and consistency checks;
- raw symbolic output for downstream Mathematica algebra;
- built-in command help and compact/full reports.

## Development status

This is a **development release**. The package is usable, but the API is not yet frozen.

Future work includes performance improvements, xAct interoperability, differential forms, vielbeins/spin connections, and higher-dimensional/supergravity functionality.
